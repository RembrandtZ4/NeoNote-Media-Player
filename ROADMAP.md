# Roadmap

🇩🇪 Deutsch | 🇬🇧 English below

Geplante Ideen für kommende Versionen. Der Schwerpunkt liegt auf **Linux** (KDE Plasma). Die Reihenfolge ist grob, nicht verbindlich. Weitere Wünsche gern als [Issue](https://github.com/RembrandtZ4/NeoNote-Media-Player/issues/new/choose).

## Als Nächstes
- [ ] **AUR-Paket** – Installation mit `yay -S neonote`
- [ ] **Intelligente Wiedergabelisten** mit eigenen Regeln (z. B. „Rock aus den 80ern, mindestens 4 Sterne, seit 3 Monaten nicht gespielt“) – wie in Windows Media Player 12
- [ ] **Feinschliff unter KDE Plasma** (Wayland, Weichzeichner, Dolphin)

## Später
- [ ] **Songtexte**, zeitgesteuert im „Wird gespielt“-Modus (z. B. über LRCLIB) und aus den Dateien selbst
- [ ] **Scrobbeln** zu Last.fm und ListenBrainz
- [ ] **Flatpak / Flathub** – für Ubuntu, Fedora, Mint und andere Distributionen
- [x] **Updater für Windows** – neue Versionen direkt aus NeoNote installieren *(fertig, kommt mit der nächsten Version)*
- [ ] **Überblenden** zwischen Titeln
- [ ] **Ordneransicht** – durch die Musikordner stöbern
- [ ] **Einschlaf-Timer** („nach 30 Minuten“, „nach diesem Album“)
- [ ] **Weiterhören an der letzten Stelle** bei Hörbüchern, Podcasts und langen Videos, Kapitelsprünge
- [ ] **Wiedergabegeschwindigkeit** für Hörbücher und Videos
- [ ] **Visualisierung** wie im Windows Media Player
- [ ] **Eigene Audioausgabe** und bitgenaue Wiedergabe (z. B. für externe DACs)
- [ ] **Auto-DJ / Radio zu einem Titel** – endlos passende Musik aus der eigenen Sammlung (Genre, Jahr, Bewertung, „wird oft zusammen gehört“)
- [ ] **Dateien umbenennen und einsortieren** nach Mustern wie „Interpret/Album/Nr. Titel“
- [ ] **Infos zum Interpreten** in „Wird gespielt“ – Biografie und ähnliche Künstler

# Roadmap (English)

Planned ideas for upcoming versions. The focus is on **Linux** (KDE Plasma). The order is rough, not binding. More ideas are welcome as an [issue](https://github.com/RembrandtZ4/NeoNote-Media-Player/issues/new/choose).

## Next
- [ ] **AUR package** – install with `yay -S neonote`
- [ ] **Smart playlists** with custom rules (e.g. “80s rock, at least 4 stars, not played for 3 months”) – like in Windows Media Player 12
- [ ] **KDE Plasma polish** (Wayland, blur, Dolphin)

## Later
- [ ] **Lyrics**, synced in “Now playing” mode (e.g. via LRCLIB) and from the files themselves
- [ ] **Scrobbling** to Last.fm and ListenBrainz
- [ ] **Flatpak / Flathub** – for Ubuntu, Fedora, Mint and other distributions
- [x] **Updater for Windows** – install new versions right from NeoNote *(done, coming with the next version)*
- [ ] **Crossfade** between tracks
- [ ] **Folder view** – browse your music folders
- [ ] **Sleep timer** (“after 30 minutes”, “after this album”)
- [ ] **Resume where you left off** for audiobooks, podcasts and long videos, chapter navigation
- [ ] **Playback speed** for audiobooks and videos
- [ ] **Visualization** like in Windows Media Player
- [ ] **Audio output selection** and bit-perfect playback (e.g. for external DACs)
- [ ] **Auto DJ / track radio** – endless matching music from your own collection (genre, year, rating, “often played together”)
- [ ] **Rename and organize files** using patterns like “Artist/Album/No. Title”
- [ ] **Artist info** in “Now playing” – biography and similar artists
