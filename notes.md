🧪 **Beta / test version** · 🇩🇪 Deutsch unten

This is a **test version** for everyone who wants to try new features early. It may still contain bugs. The regular version is still [1.3.1](https://github.com/RembrandtZ4/NeoNote-Media-Player/releases/latest).

**Download:**
- **Windows 10/11:** `NeoNote-Setup-1.3.1.99.exe` – install over your existing NeoNote, settings and library are kept.
- **Arch Linux / CachyOS:** `neonote-1.3.1.99-linux-arch.zip` – unpack and run `./install.sh`. If you already use the Arch zip of 1.3.1.98, NeoNote offers this update itself.
- **Flatpak:** test builds are available in the [test](https://github.com/RembrandtZ4/NeoNote-Media-Player/releases/tag/test) pre-release.

**Get test versions automatically:** Settings ▸ System (or ▸ About) ▸ “Also offer test versions (beta)”.

### ✨ New features
- **Ready for the AUR:** the Arch packages now record whether they come from the Arch zip or (later) from the AUR. Installed from the AUR, regular updates come via `yay -Syu`, while test versions (only available as a zip) are still installed by NeoNote itself.

### 🐞 Bug fixes
- Windows: after installing or updating, an empty folder “NeoNote-Setup.tmp” could be left behind in “Program Files”. The installer now removes it reliably; the uninstaller also cleans up leftovers from older versions. Reported by Holgi in the Deskmodder forum.

🧪 **Beta / Testversion**

Das ist eine **Testversion** für alle, die neue Funktionen früh ausprobieren möchten. Sie kann noch Fehler enthalten. Die reguläre Version ist weiterhin [1.3.1](https://github.com/RembrandtZ4/NeoNote-Media-Player/releases/latest).

**Download:**
- **Windows 10/11:** `NeoNote-Setup-1.3.1.99.exe` – einfach über das vorhandene NeoNote installieren, Einstellungen und Bibliothek bleiben erhalten.
- **Arch Linux / CachyOS:** `neonote-1.3.1.99-linux-arch.zip` – entpacken und `./install.sh` ausführen. Wer schon die Arch-Zip der 1.3.1.98 nutzt, bekommt dieses Update direkt von NeoNote angeboten.
- **Flatpak:** Testpakete gibt es in der Vorabversion [test](https://github.com/RembrandtZ4/NeoNote-Media-Player/releases/tag/test).

**Testversionen automatisch bekommen:** Einstellungen ▸ System (oder ▸ Über) ▸ „Auch Testversionen (Beta) anbieten“.

### ✨ Neue Funktionen
- **Bereit fürs AUR:** Die Arch-Pakete merken sich jetzt, ob sie aus der Arch-Zip oder (später) aus dem AUR stammen. Aus dem AUR installiert, kommen reguläre Updates per `yay -Syu`; Testversionen (gibt es nur als Zip) installiert NeoNote weiterhin selbst.

### 🐞 Behobene Fehler
- Windows: Nach dem Installieren oder Aktualisieren konnte ein leerer Ordner „NeoNote-Setup.tmp“ in „Programme“ zurückbleiben. Der Installer entfernt ihn jetzt zuverlässig, der Deinstaller räumt auch Reste älterer Versionen weg. Gemeldet von Holgi im Deskmodder-Forum.
